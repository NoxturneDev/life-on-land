BAB I: PANDUAN INSTALASI DAN SETUP LINGKUNGAN

Bab ini menjelaskan langkah-langkah teknis untuk melakukan instalasi dan konfigurasi lingkungan pengembangan perangkat lunak (development environment) pada laptop/PC untuk menjalankan dan meng-compile game Life on Land.

1.1 Persyaratan Sistem (Prerequisites)

Sebelum memulai proses setup dan kompilasi proyek, pastikan laptop/PC Anda telah terpasang beberapa perangkat lunak dasar berikut:

No Perangkat Lunak / Spesifikasi Kebutuhan Versi & Keterangan
1 Unity Hub & Unity Engine Versi Unity 6 (6000.0.x) / 2022.3 LTS (Windows/Mac Build Support & WebGL).
2 Git Version Control Git CLI v2.x terinstal untuk mengunduh dan mengelola repositori.
3 PlayFab SDK PlayFab Unity Editor Extensions / SDK v2.x terintegrasi di project.
4 Spesifikasi Minimum PC Intel Core i3 / AMD Ryzen 3, RAM 8 GB, GPU Intel UHD / GTX 750, OS Windows 10/11 64-bit.

1.2 Panduan Langkah-Langkah Instalasi dan Kompilasi

Langkah 1: Mengunduh Source Code Proyek

Buka terminal atau Command Prompt pada laptop Anda, lalu jalankan perintah berikut:

git clone https://github.com/NoxturneDev/life-on-land.git
cd "My project"

Langkah 2: Membuka Proyek di Unity Engine

  1. Jalankan Unity Hub.
  2. Klik tombol Add -> Add project from disk.
  3. Pilih folder direktori root proyek My project.
  4. Pilih versi editor Unity 6 atau Unity 2022.3 LTS, lalu klik untuk membuka proyek.
  5. Tunggu proses importing assets dan package resolution selesai (2–5 menit saat pertama kali).

Langkah 3: Konfigurasi SDK PlayFab Manager

  1. Di dalam Unity Editor, buka window menu: Window -> PlayFab -> EdEx.
  2. Masukkan Title ID PlayFab proyek Anda (misal: 1A2B3).
  3. Pastikan file PlayFabSharedSettings di folder Resources terisi Title ID secara akurat agar fitur Cloud Save dan Leaderboard aktif.

Langkah 4: Menjalankan Game di Unity Editor

  1. Di panel Project, navigasi ke folder Assets/Scenes/.
  2. Klik ganda pada scene MainMenuScene.unity atau BasicScene.unity.
  3. Tekan tombol Play (▶) di bagian atas Unity Editor. Game siap dimainkan.

Langkah 5: Meng-compile Executable Build (Windows PC & WebGL)

  1. Pilih menu File -> Build Settings...
  2. Pastikan daftar Scenes In Build mencakup:
    • Assets/Scenes/MainMenuScene.unity (Index 0)
    • Assets/Scenes/BasicScene.unity (Index 1)
  3. Pilih Platform Standalone Windows (x86_64) atau WebGL.
  4. Klik tombol Build, lalu buat folder tujuan Builds/.
  5. Unity akan menghasilkan eksekusi LifeOnLand.exe atau bundel WebGL.

public class Player : MonoBehaviour {
    [SerializeField] private float baseMovementSpeed = 5.0f;
    [SerializeField] private float currentStamina = 100.0f;
    [SerializeField] private float localO2Buffer = 10.0f;
